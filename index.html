Visit Seoul API Project

비짓서울 API 데이터 분석 및 AI 관광서비스 프로토타입 연구

2026 서울관광재단 「비짓서울 API 데이터·AI 활용 아이디어 공모전」 참가를 위해 비짓서울 관광 콘텐츠 데이터의 구조와 활용 가능성을 분석하고, 외부 데이터와의 결합 가능성을 조사하며, AI 기술을 활용한 신규 관광서비스 아이디어와 프로토타입을 연구하는 프로젝트 사이트입니다.

연구 범위

  • 비짓서울 관광 콘텐츠 데이터 구조 및 활용 가능성 분석
  • 외부 데이터(공공·실시간·통계)와의 결합 가능성 조사
  • AI 기술을 활용한 신규 관광서비스 아이디어 및 프로토타입 연구

비짓서울 API 활용 계획

  • 카테고리·언어 코드·콘텐츠 목록·콘텐츠 정보 API 호출
  • 8개 카테고리 × 7개 언어 콘텐츠의 필드 충실도·갱신 특성 조사
  • 조사 결과를 바탕으로 한 AI 관광서비스 프로토타입 설계
