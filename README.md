# Visit Seoul API Project

2026 서울관광재단 비짓서울 API 데이터·AI 활용 아이디어 공모전 참가를 위한 데이터 분석 및 서비스 프로토타입 저장소입니다.

## Purpose

- 비짓서울 API의 데이터 구조와 활용 가능성 분석
- 외부 데이터 및 AI 기술과 결합한 신규 관광 서비스 아이디어 연구
- 공모전 제출용 서비스 프로토타입 및 분석 결과 정리

## Status

현재는 API 구조 조사 및 서비스 기획 단계입니다.
